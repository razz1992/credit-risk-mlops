## Evidence rules

- Only publish actual outputs generated by completed runs.
- Never fabricate model scores or claim deployment that was not performed.
- Include dataset provenance and limitations.
- Do not include secrets, private customer data, raw personal information, or local machine-specific details.
- Prefer small plots, JSON metrics, Markdown summaries, and notebook source. Keep large datasets and binary model files out of Git unless there is a clear reason.
