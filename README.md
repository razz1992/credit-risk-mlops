# Credit Risk ML — Production-Style Learning Project

A hands-on supervised ML project to train, evaluate, package, and serve a credit-default classifier. A one-to-two-day learning exercise.

> Educational use only. This is not a credit decision system and must not be used for real lending decisions.

## Status
Bootstrap / planning. See [planning.md](planning.md) for scope, schedule, architecture, risks, and definition of done.

## Planned capabilities
- UCI dataset ingestion and data validation
- Leakage-aware preprocessing and stratified splits
- Logistic Regression baseline and tree-based model comparison
- Validation threshold selection and held-out test evaluation
- Experiment tracking and model packaging
- FastAPI inference endpoint
- Tests, GitHub Actions CI, and portfolio case study

## Dataset
UCI Default of Credit Card Clients (ID 350). See [official record](https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients), cite dataset authors, and follow CC BY 4.0 terms.
